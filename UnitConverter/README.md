# 1 Unit/Currency Converter

## Functional Requirements:
1. Minimum 3 different unit categories (distance, weight, currency, etc.).
2. Not less than 3 different units in each category.
3. A digital keyboard, similar to a calculator, and two fields for the original and converted values. The user should not be able to change the data in these fields using the standard system keyboard.
4. It is recommended to arrange the keyboard and the data area as separate Fragments Android. Portrait orientation: the fragments are arranged in two rows (the keyboard is under the data fragment). Landscape orientation: fragments in one row (data on the left, keyboard on the right).
5. Create build flavor "premium". There should be a button that will swap the original and converted values (and units of measurement), and vice versa. A button to copy the current value to the clipboard next to each data entry field. Use source sets to define different layouts and code files for each flavor option.
